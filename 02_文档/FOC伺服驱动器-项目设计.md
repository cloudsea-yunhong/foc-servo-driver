# FOC 无刷伺服电机驱动器 —— 项目设计文档

> 平台：STM32F407VET6 + FreeRTOS + 有感 FOC 三环伺服
> 硬件约束：**全程零焊接**
> 定位：实验室级伺服驱动器（控制结构完整，性能指标为教学级）

---

## 1. 项目定义

### 1.1 一句话

在 STM32F407 上用 FreeRTOS 做任务框架、用硬件中断承载控制环，自研一套有感 FOC 三环伺服驱动器：Clarke/Park 变换、SVPWM、电流环 20 kHz、速度环与位置环 1 kHz，带速度前馈、三重限幅、多圈计数，配套上位机做三环在线整定与波形记录。

### 1.2 技术栈

| 层 | 内容 |
|---|---|
| 实时层 | 高级定时器互补 PWM + 死区、ADC 同步采样、硬件中断 |
| 控制层 | Clarke/Park、SVPWM、双 PI、位置 P、速度前馈、三重限幅 |
| RTOS 层 | FreeRTOS 任务/队列/通知/临界区、中断与任务边界设计 |
| 通信层 | 串口协议（命令/应答/遥测）、DMA burst 波形上传 |
| 存储层 | Flash 参数保存、掉电恢复 |

### 1.3 验收指标

| 指标 | 目标值 | 测量方法 |
|---|---|---|
| PWM 载波 | 20 kHz 中心对齐 | 逻辑分析仪 |
| 电流环频率 | 20 kHz | GPIO 翻转 + 逻辑分析仪 |
| 电流环精度 | 给定 1 A，实测 1 A ±5% | 上位机记录 |
| 电流环阶跃 | 0→1 A，建立时间 < 1 ms | 上位机记录 |
| 速度环频率 | 1 kHz | GPIO 翻转 |
| 速度环精度 | 给定 1000 rpm，±1% | 上位机记录 |
| 位置环频率 | 1 kHz | 同上 |
| 定位精度 | ±0.3°（12 bit 编码器限制） | 给 90°，记录稳态误差 |
| 位置阶跃 | 0→90°，< 300 ms，超调 < 10% | 上位机记录 |
| 零速保持 | 手推 5° 后能回原位 | 手动 |
| 电流环 ISR 执行时间 | < 10 µs（占周期 20%） | GPIO 测量 |
| 任务栈使用率 | < 70% | `uxTaskGetStackHighWaterMark` |
| CPU 空闲率 | > 30% | `vTaskGetRunTimeStats` |

## 2. 系统架构

### 2.1 分层

```
┌─────────────────────────────────────────────┐
│ 上位机 (Python)                              │
│  命令下发 / 参数整定 / 波形显示               │
└──────────────────┬──────────────────────────┘
                   │ UART 115200
┌──────────────────▼──────────────────────────┐
│ FreeRTOS 任务层（非实时业务）                 │
│  CommTask / ControlTask / TelemetryTask      │
│  ParamTask / MonitorTask                     │
└──────────────────┬──────────────────────────┘
                   │ 队列 / 任务通知 / 双缓冲参数
┌──────────────────▼──────────────────────────┐
│ 硬件中断层（实时控制）                        │
│  TIM1 Update ISR (20 kHz)：电流环            │
│    └─ 每 20 次：速度环 + 位置环 (1 kHz)       │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│ 外设层                                       │
│  TIM1(3路PWM) / ADC1(双通道+DMA) /           │
│  I2C-GPIO(AS5600) / USART2                   │
└─────────────────────────────────────────────┘
```

### 2.2 核心设计决策：控制环放中断，RTOS 只管业务

**这是整个项目最重要的一个判断，也是面试最有价值的一句话：**

> FreeRTOS 的任务调度抖动通常是几十微秒量级，而 20 kHz 电流环的周期只有 50 µs。把电流环放进任务，调度抖动会直接摧毁控制质量。所以控制环必须跑在硬件中断里，RTOS 只负责非实时业务。

| 放在哪里 | 内容 | 原因 |
|---|---|---|
| **硬件中断** | 电流环、速度环、位置环、ADC 读取、SVPWM 输出 | 需要确定性周期，抖动 < 1 µs |
| **FreeRTOS 任务** | 串口通信、参数管理、遥测上传、状态机、监控 | 允许毫秒级抖动 |

## 3. FreeRTOS 任务设计

### 3.1 任务表

| 任务 | 优先级 | 栈 | 触发方式 | 职责 |
|---|---|---|---|---|
| **TIM1_UP_ISR** | NVIC 4 | — | 20 kHz | ADC 读取 → Clarke/Park → 电流 PI → 反 Park → SVPWM；每 20 次执行速度/位置环 |
| **ControlTask** | 5 | 512 W | 任务通知（来自 ISR） | 状态机：IDLE / ALIGN / RUN / FAULT；模式切换；安全监控 |
| **CommTask** | 4 | 768 W | 队列（串口中断投递） | 命令解析、应答、参数修改请求 |
| **TelemetryTask** | 3 | 1024 W | 任务通知 | DMA burst 数据打包、上传 |
| **ParamTask** | 2 | 512 W | 事件组 | Flash 参数读写、掉电保存 |
| **MonitorTask** | 1 | 384 W | 1 s 周期 | 温度、母线电压、故障计数、LED 心跳 |

### 3.2 中断优先级约束（最容易踩的坑）

FreeRTOS 在 Cortex-M4 上的规则：

```
NVIC 优先级数值越小 = 优先级越高
configMAX_SYSCALL_INTERRUPT_PRIORITY = 5   （数值）
```

**规则：所有调用 `...FromISR()` API 的中断，NVIC 优先级数值必须 ≥ 5。**

| 中断 | NVIC 优先级 | 能否调用 RTOS API |
|---|---|---|
| TIM1_UP（电流环） | **4** | ❌ **绝对不能** |
| USART2（串口） | 6 | ✅ 可以 |
| EXTI（nFAULT） | 7 | ✅ 可以 |
| FreeRTOS SysTick | 15 | ✅ |

**如果电流环 ISR 想用最高优先级（4），就一条 RTOS API 都不能调**，只能置 `volatile` 标志位。违反这条会在 `configASSERT` 里死循环，且极难定位。

### 3.3 任务间通信

```
ISR ──(volatile 标志)──► ControlTask   ← 不用 FromISR，避免优先级陷阱
ISR ──(xTaskNotifyFromISR)──► 仅限 优先级 ≥5 的中断
CommTask ──(队列)──► ControlTask       ← 模式切换命令
CommTask ──(双缓冲指针)──► ISR         ← 参数更新
ISR ──(DMA 环形缓冲)──► TelemetryTask  ← 波形数据
```

### 3.4 参数原子更新（双缓冲 + 指针交换）

**问题：** 任务改 PI 参数时，20 kHz 中断随时可能打断，读到"改了一半"的参数组合 → 控制瞬间发散。

**方案：**

```c
typedef struct {
    float kp_i, ki_i;          // 电流环
    float kp_w, ki_w;          // 速度环
    float kp_p;                // 位置环
    float kff_w;               // 速度前馈
    float lim_v, lim_i, lim_u; // 三重限幅
    float f_notch, q_notch;    // 陷波（可选）
} ControlParams;

static ControlParams      g_buf[2];
static ControlParams * volatile g_active = &g_buf[0];
static volatile uint8_t   g_write_idx = 1;

/* 任务侧：写非活动缓冲，写完原子切换指针 */
void params_update(const ControlParams *p)
{
    g_buf[g_write_idx] = *p;
    __DMB();                        /* 保证数据写完再切指针 */
    g_active = &g_buf[g_write_idx];
    g_write_idx ^= 1;
}

/* ISR 侧：只读活动缓冲，单周期内不重读 */
const ControlParams *p = g_active;
```

**为什么安全：** Cortex-M4 上 32 位指针赋值是原子的；`__DMB()` 保证结构体数据先写完。ISR 永远读到一个完整一致的参数块。

## 8. 关键实现要点

### 8.1 PWM + ADC 同步（最容易做错的地方）

| 项 | 配置 |
|---|---|
| 定时器 | TIM1，中心对齐模式 1（CMS=01） |
| 载波频率 | 20 kHz（168 MHz，ARR 按 PSC 算） |
| 死区 | BDTR.DTG，先设 1 µs |
| TRGO | Update event |
| ADC 触发 | TIM1_TRGO（外部触发，不用软件启动） |
| 采样通道 | 双通道（注入组或规则组 + DMA） |
| 采样时刻 | **必须是 PWM 中心点（计数器=0 附近，低侧 MOS 导通）** |

**坑：** 中心对齐模式下 Update 事件在上溢和下溢各产生一次，ADC 会触发两次/周期。两种处理：

- 用 TIM1 的 **RCR（重复计数器）** 控制 UEV 频率
- 或在 ISR 里用奇偶计数判断，只取"下溢"那一次的数据

**为什么必须在下溢采样：** 只有低侧 MOS 导通时，分流电阻上的电流才等于相电流；高侧导通时采样到的是母线电流或无效值。

### 8.2 执行顺序（每个 20 kHz 周期）

```c
void TIM1_UP_IRQHandler(void)   // NVIC 优先级 4，禁止调用 RTOS API
{
    /* 1. 读 ADC（电流 Ia/Ib，母线 Vbus） */
    /* 2. 读角度（由 1 kHz 速度环 ISR 预先更新，此处只取） */
    /* 3. Clarke：Ia/Ib → Iα/Iβ */
    /* 4. Park：Iα/Iβ + θe → Id/Iq */
    /* 5. 电流 PI：Iq* → Uq, Id* (=0) → Ud */
    /* 6. 三重限幅：Uq 幅值 ≤ Vbus/√3 */
    /* 7. 反 Park：Ud/Uq + θe → Uα/Uβ */
    /* 8. SVPWM：Uα/Uβ → 三路占空比 */
    /* 9. 写 CCR1/2/3 */
    /* 10. 每 20 次：调用 speed/position 控制 */
}
```

### 8.3 速度环与位置环（1 kHz）

```c
if (++div20 >= 20) {
    div20 = 0;

    /* 速度环 */
    theta = encoder_read();              // AS5600 阻塞读约 150 µs，安全
    omega = (theta - theta_last) / dt;   // 差分
    omega = lpf(omega);                  // 一阶低通，fc ≈ 100 Hz
    Iq_sp = pi_speed(omega_sp - omega);  // 输出电流给定

    /* 位置环（三环模式时） */
    omega_sp = p_position(theta_sp - theta) + kff_w * omega_cmd;
    omega_sp = clamp(omega_sp, ±lim_v);  // 限速
    Iq_sp    = clamp(Iq_sp, ±lim_i);     // 限流
}
```

**注意顺序：** 位置环输出 → 速度环给定 → 速度环输出 → 电流给定。外环套内环，不能反。

### 8.4 三重限幅（少一层就会飞车）

| 层 | 限制什么 | 依据 |
|---|---|---|
| 位置环输出 | 速度给定 ≤ 额定转速 | 防止 180° 阶跃要求无限速度 |
| 速度环输出 | 电流给定 ≤ 驱动板峰值 | 防止过流炸管 |
| 电流环输出 | 电压幅值 ≤ Vbus/√3 | 防止调制饱和失控 |

### 8.5 多圈计数（不做会跳变）

```c
static int32_t turns;
static uint16_t last_raw;

void encoder_update(uint16_t raw)
{
    if ((int32_t)raw - (int32_t)last_raw < -2048)      turns++;
    else if ((int32_t)raw - (int32_t)last_raw >  2048) turns--;
    last_raw = raw;
}
float encoder_angle(void) {
    return turns * 2.0f * M_PI + last_raw * (2.0f * M_PI / 4096.0f);
}
```

### 8.6 电流采样校准（上电必做）

```c
/* 上电时：断开 PWM 或占空比 50%，读 N 次 ADC 求偏置 */
for (int i = 0; i < 256; i++) {
    off_a += adc_ia();  off_b += adc_ib();
}
off_a /= 256;  off_b /= 256;

/* 运行时 */
Ia = (adc_ia() - off_a) * K_scale;   // K_scale = 1/(gain * R_shunt * ADC_LSB)
```

## 11. 面试要点

### 11.1 必答题

| 问题 | 要点 |
|---|---|
| 为什么电流环放中断不放任务？ | RTOS 调度抖动几十 µs，20 kHz 周期只有 50 µs，抖动会摧毁控制 |
| 电流环和速度环为什么差 20 倍？ | 内环带宽必须远高于外环（5–10 倍），否则外环失稳 |
| 采样为什么必须在 PWM 中点？ | 只有低侧 MOS 导通时，分流电阻电流才等于相电流 |
| 三重限幅各限什么？ | 位置→速度、速度→电流、电流→电压 |
| 多圈计数怎么做？ | 相邻读数差 > 2048 判定跨界，累计圈数 |
| 参数在线修改怎么保证不撕裂？ | 双缓冲 + 指针原子交换 + DMB |
| 死区为什么要插？插多少？ | 防止上下桥直通；1 µs 是 MOSFET 关断时间的经验值 |
| 你的 RTOS 中断优先级怎么排的？ | 电流环 4（不调 API）、串口 6、EXTI 7、SysTick 15 |

### 11.2 边界声明（被问"是不是工业级"时）

> "控制结构是完整的——三环串级、速度前馈、三重限幅、零速保持。差的是硬件性能：12 bit 编码器分辨率约 0.088°、云台电机过载只有 1.5 倍、没有 STO 安全功能和 EMC 设计。所以我做的是三环控制结构和实时框架，不是工业级精度指标。"

### 11.3 简历写法

> **FOC 无刷伺服电机驱动器（STM32F407 + FreeRTOS）**
> 自研 Clarke/Park 变换与七段式 SVPWM，实现电流环 20 kHz、速度/位置环 1 kHz 的串级三环控制，含速度前馈、三重限幅、多圈计数与参数双缓冲原子更新；用 FreeRTOS 承载通信/参数/遥测业务，控制环运行于硬件中断以保证确定性（ISR < 10 µs）。配套上位机实现在线整定与波形记录。实测：定位精度 ±0.3°，0→90° 阶跃 280 ms，零速带载保持。
