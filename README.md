# 无刷电机 FOC 三环伺服驱动器

> STM32F407 + DRV8316 + MT6701 | Clarke / Park / SVPWM | 电流环 / 速度环 / 位置环全闭环

一个从零搭建的无刷电机磁场定向控制（FOC）伺服驱动器。

---

## 实测性能

| 控制环 | 指标 | 实测 |
|---|---|---|
| **电流环** | 稳态跟踪精度 | **±1 ~ 4 %**（100 / 200 / 300 / 500 mA） |
| | 电压-电流线性度 | vq = 390 / 695 / 996 / 1302 mV → 100 / 200 / 300 / 500 mA |
| **速度环** | 上升时间（0 → 9 rad/s） | **80 ms** |
| | 稳态误差 | **0.5 %**（目标 10 rad/s，实测 9.95） |
| **位置环** | 到达 ±1 % 时间 | **1100 ms**（1 圈阶跃） |
| | 稳态误差 | **4 %**（250 mrad） |
| | 超调 | **4.25 %** |

**PWM**：20 kHz 中心对齐，SVPWM min-max 中点注入  
**控制环**：1 kHz（ADC 轮询采样，见「已知限制」）  
**编码器**：MT6701 ABZ，TIM3 四倍频，PPR = 1024（实测 1023.68，误差 0.03 %）

## 关键技术点

### 1. 低侧电流采样 + 时间窗口同步
DRV8316 的低侧采样电阻**只在低边 MOSFET 导通时**反映真实相电流。固件在 TIM1 计数接近波峰时采样，实测采样脉冲位于 PWM 低电平窗口内（下降沿后 3.7 µs）。

### 2. 两相重构
CS1 通道读数异常，改用 `Ia = -(Ib + Ic)`（基尔霍夫电流定律）重构 A 相电流

### 3. 上电零点自动校准
上电时连续采集 64 次求平均得到三路采样零点（实测 2057 / 2058 / 2058），失败时自动重试 12 次并等待 12 V 上电。

### 4. 非阻塞串口
改用环形缓冲 + TXE 中断发送，替代 `HAL_UART_Transmit` 阻塞调用。**此前每行阻塞 9.5 ms，把控制环从 1 kHz 拖慢到 50 Hz，导致电机剧烈震动。**

### 5. 多重保护
- 电流限幅（0.5 A）
- 圆形电压限幅（7.2 V，保持矢量角度）
- 力矩模式超速折叠（>120 rad/s 按比例衰减）
- FAULT 状态互锁（标定失败时拒绝一切运动命令）

### 6. 编码器信号镜像
编码器 A/B 为开漏输出，直接接逻辑分析仪会失去 MCU 内部上拉而无法观测。固件在 20 kHz 中断里把 PC6/PC7 电平复制到 PB1/PB12，既保留 MCU 输入，又能用分析仪观测。

## 调试过程中解决的关键问题

1. **SVPWM 使用 switch 之前的旧角度** → 磁场完全不转、占空比冻结在 1215/3526/672
2. **3 次 `sinf` 拖垮 20 kHz 中断** → 改用 256 点查表
3. **UART 阻塞发送拖慢控制环** → 环形缓冲 + TXE 中断
4. **ADC 采样落在高边导通窗口** → 计数器同步等待低边窗口
5. **CS1 通道读数无效** → 两相重构
6. **`sscanf("%f")` 在 newlib-nano 不支持** → 改用 `atoi` + 整数毫单位
7. **开环角度增量用除号而非乘号** → 角度溢出
8. **`ENC_DIR_SIGN` 与电机的相对安装方向不一致** → 闭环输出错误力矩

## 已知限制

| # | 限制 | 原因 |
|---|---|---|
| **1** | **电流环运行在 1 kHz，非 20 kHz** | ADC 软件轮询单次转换 7.45 µs，三通道 22.4 µs + 运算 10 µs，占满 50 µs 周期的 65%。要提升到 20 kHz 需改为 TIM 硬件触发 + DMA |
| **2** | 位置环超调 4.25 % | 纯 PI 串级控制、二阶欠阻尼（ζ≈0.72）的固有特性。彻底解决需要梯形速度规划 |
| **3** | 位置环稳态误差 4 % | 与上一项同源 |
| **4** | 空载力矩模式测不准阶跃响应 | 恒定力矩驱动空载电机会持续加速，反电动势限制电流 |
| **5** | FreeRTOS 未启用 | CubeMX 提供的 `RVDS/ARM_CM4F` 端口使用 ARMCC 5 的 `__asm void` 语法，armclang 不支持；改用 GNU 端口需重写上下文切换 |
